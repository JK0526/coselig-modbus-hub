# Coselig Modbus Hub v1.6.5-beta.3

本版為公開測試版，延續 beta.2 的功能與修復，供使用者實際驗證批次新增。

- 掃描結果可勾選「全部新增（使用預設輸出模式）」，也可使用原有的手動新增流程。
- 高可信度 P404／P210 與已辨識的 R410 可直接套用。低可信度或未知型號可選取多台相同型號的設備，依設備標示批次確認。
- 調光器預設為獨立調光，R410 預設為一般 Switch。現有設備及本次未掃到的設備會保留，啟用 S402 時略過 Slave #1。確認摘要後才會儲存。

## 已知限制

繁體中文介面完整化與 Modbus Monitor 翻譯尚未完成。部分動態文字仍可能顯示英文，掃描結果描述的語系問題仍待在 Home Assistant 瀏覽器中驗證。

## HACS 安裝

開啟此整合的預發布更新選項，在 HACS 選擇「重新下載」及 `v1.6.5-beta.3`，下載後重啟 Home Assistant。穩定版為 `v1.6.4`。
