# Coselig Modbus Hub v1.4.0-beta.2

**Beta / Hardware validation build. Hardware acceptance pending.** The previous stable baseline remains v1.3.3; this is not the stable v1.4.0 release.

- Fix multiple S402 parent device display names (`S402 #ID`) without changing registry identifiers or EventEntity unique IDs.
- Add admin-only runtime background Poll pause/resume controls to Modbus Monitor.
- Runtime Poll control does not modify the saved `poll_interval`; the runtime pause clears on integration reload.
- Control, Scanner, Continuous RX, S402 EVENT, Monitor, and reconnect remain active while background polling is paused. An in-flight request completes, and resume uses the existing scheduler without building a backlog.
- `poll_interval = 0` remains disabled and cannot be runtime-resumed.
- Config Entry schema remains 2.1. P404, P210, and R410 protocol behavior is unchanged.
- Hardware validation continues. In particular, S402 coexistence with existing Poll / Control still requires real-device acceptance.

Automated validation: **520 Python tests**, **39 frontend tests**, **99.75% branch coverage**, and **100% Config Flow line / branch coverage**. Hardware acceptance remains pending.
