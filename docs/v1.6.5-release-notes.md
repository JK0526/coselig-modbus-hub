# Coselig Modbus Hub v1.6.5

正式版沿用已通過實機驗收的 v1.6.5-beta.7。此版本只更新版本資訊與發布文件。

| 測試版 | 納入正式版的變更 |
| --- | --- |
| beta.1 | P210／P404 自動辨識與型號修正、單台 Slave 獨立退避、TCP 軟重置與後續輪詢恢復。修復卸載時 Future 懸掛、重複 Gateway 及並行 Options Flow 覆蓋設定。 |
| beta.2 | 修復 Light／Switch 樂觀狀態回復、CCT 成對入列、舊命令結果覆蓋新狀態，以及 Reload／Unload 中斷掃描的清理。 |
| beta.3 | 新增掃描結果「全部新增」，可自動套用高可信度型號或批次確認待辨識設備。保留手動設定、既有設備及 S402 位址保護。 |
| beta.4 | Monitor 加入預設關閉的管理員被動 RX 監聽。Poll=0 時可在既有連線上觀察 Gateway 轉送的完整未配對回覆。 |
| beta.5 | Monitor 統一封包時間軸，支援未配對 RX 篩選、HEX、功能碼及 CRC 檢視。 |
| beta.6 | 管理員可透過 Monitor 發送單筆 FC01～FC06、FC0F 或 FC10 RTU HEX，選擇自動附加 CRC 或保留原始 CRC。Worker 先排空已接受的交易，手動操作期間拒絕新控制與輪詢。寫入會直接影響設備。 |
| beta.7 | MANUAL 狀態獨立顯示、HEX 起點對齊，手動指令表單在桌面與手機分區排列。 |

## 已知限制

Gateway 在極端情況下可能把串列緩衝中的延遲回覆轉送到新 TCP 連線。TCP 重建與 100 毫秒重連間隔無法保證這些回覆已清除。同一 Slave、功能碼與回覆長度的讀取尤其難以區分。整合不會自動重送結果不明的控制命令。被動監聽只能看到 Gateway 實際轉送的封包；部分介面動態文案仍可能顯示英文。

## HACS 更新

更新至 v1.6.5 後重新啟動 Home Assistant，並重新整理 Monitor 網頁。已安裝 beta 的使用者可在 HACS 的「重新下載」選擇 v1.6.5。既有 Config Entry schema 維持 2.1。
