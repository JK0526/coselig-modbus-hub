# Coselig Modbus Hub v1.6.5-beta.6

在 Monitor 選擇閘道器並展開「手動指令」。管理員可貼上一筆 FC01～FC06、FC0F 或 FC10 的 Modbus RTU HEX，送出後在原始封包時間軸查看 MANUAL 交易。

- 勾選自動 CRC 時，請輸入不含 CRC 的資料。整合會附加低位元組與高位元組。
- 取消勾選時，請輸入完整 RTU 封包。整合會保留原始位元組，包括故意提供的錯誤 CRC。
- Slave 1 的 FC06／0x01A0 保留給 S402 事件。手動發送會拒絕這個簽章，以免寫入回音被辨識為事件。
- 寫入會直接影響實體設備。交易期間新的 HA 控制會被拒絕，既有已接受交易會先排空。逾時後不會重送。
- 逾時或錯誤依原有政策清理 TCP。重建 TCP 無法保證 Gateway 的串列緩衝不會將延遲回覆轉送到新連線。

在 HACS 啟用預發布更新，重新下載 v1.6.5-beta.6 並重啟 Home Assistant。
