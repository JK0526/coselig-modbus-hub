# Coselig Modbus Hub v1.1.1

日期：2026-10-14。

## P210 CCT 修正

- P210 的 Group A 可選 `single` 或 `cct`，預設為 `single`。
- `single` 建立 CH1、CH2；`cct` 只建立雙色溫 A，使用 `0x082A`、`0x082B`。
- P210 single 與 CCT 都維持 FC03 `start=0x082A`、`count=2`；P404 維持 count 4。
- v1.1.0 既有 P210 設定缺少 `group_a` 時，讀取時自動視為 `single`，不需要刪除 Entry 或重新加入。
- P404 的 Group A／Group B、brightness／color-temperature conversion、optimistic state 與 poll correction 沿用既有實作。

切換模式時使用既有 Entity Registry lifecycle：不再使用的輸出會被移除，需要的輸出會依相同 unique ID 規則重建；未被移除的 entity 名稱與原生 Area 不會被整合覆寫。

## Monitor 顏色

Monitor backend、TraceBuffer、WebSocket protocol、暫停與清除行為均不變。前端只增加 presentation class：TX 藍色系、RX／OK 綠色系、TIMEOUT 黃／橘色系、CRC ERROR／ERROR 紅色系，timestamp／latency 使用次要文字色，Raw HEX 沿用 TX／RX 色系。顏色取自 Home Assistant theme CSS variables，支援 Light／Dark theme。
