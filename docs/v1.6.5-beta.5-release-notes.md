# Coselig Modbus Hub v1.6.5-beta.5

Monitor 的原始封包列表依時間顯示正常 Trace、S402 事件與未配對 RX。管理員可在 Poll=0 啟用被動監聽，用 Slave 或「未配對 RX」篩選，點選後查看原始 HEX、功能碼及 CRC。後端仍使用獨立且有容量上限的被動緩衝。

在 HACS 啟用預發布更新，重新下載 v1.6.5-beta.5 並重啟 Home Assistant。
