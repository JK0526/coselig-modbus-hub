## C. Modbus Monitor

`ProtocolTraceBuffer` 預設200筆、上限500筆，deque為固定容量，僅記憶體，不讀寫資料庫／檔案／Recorder。TX在送出前記錄，完整RX在CRC驗證前記錄，驗證後記OK、CRC ERROR、TIMEOUT、ERROR與latency。timestamp使用UTC ISO含毫秒，UI換成瀏覽器本地時間；source分poll／control／scan。

Transport只新增觀察支路，request／response／CRC／timeout／單筆in-flight／priority／coalescing不改。trace record例外被隔離，測試證明不影響交易成功／失敗與封包數。

管理員側欄 `Coselig Modbus Monitor`，backend只有list／subscribe／clear。每0.5秒讀取快照，只在改變時推送，不發任何Modbus request。WS斷線／取消清timer，reload時訂閱改讀同Entry的新runtime。JS單一custom element，無外部套件，使用textContent呈現，僅Gateway選擇、清除、暫停／繼續；不提供通道／設備CRUD、register寫入、scanner或polling管理。暫停只凍結畫面，最新快照仍200筆上限，Modbus與Recorder均不受影響。

靜態module URL含1.1.0，避免固定URL載入舊JS。UI完整生命週期由4項Node DOM harness測試，未聲稱已在現場HA browser／Companion App完成驗收。

## D. Poll=0

0代表停止背景FC03，scheduler等待Event；不忙迴圈、不增加未發生交易的failure、不更動最後狀態。寫入、CCT、Scanner、Monitor與連線仍可用。0→非零立即喚醒並poll。非零僅接受≥0.5；NaN／infinity／負值／過快週期拒絕。

Options polling step使用 `automatic_reload=False`，同步修改同一coordinator，保存options，不重新載入平台；設備profile變更仍沿用原生自動reload。2→0會讓在途交易完成，後續Slave背景讀取停止。

restart沒有runtime cache，所以保留一次初始化讀取取得狀態。paused reconnect不增加FC03，只恢復原先已確認且failure<3的設備可用性；資料仍為最後已知。外部變更、失敗write的真實校正需恢復poll或明確HA manual refresh。正常非零的逐Slave輪詢、單筆socket／priority／latest-wins／capacity32／backoff／故障隔離全部保留。

## E. Area

每Slave仍一個HA Device，Device不設定Area／suggested_area。使用者在各LightEntity設定頁分別選HA原生Area，例如CH1客廳、CH2餐廳、CH3玄關、CH4廚房。無area mapping、room欄位或額外Device。

Regression以真正Registry分配四個不同area_id與自訂名稱，驗證reload、rescan、polling options後完全保留。Mode switch僅替換指定Group，已刪輸出的metadata不保證恢復；另一Group的registry不改。

## F. Diagnostics

新增 `polling_paused`、`configured_slaves`、`available_slaves`、`last_poll_round_ms`、`average_poll_round_ms`。Round只量測輪詢lock取得後到本輪最後一次完成，不含lock等候或下一輪等待。平均用最近20輪deque；空值0，runtime重啟歸零。

原有queue／success／fail／timeout／CRC／reconnect與per-device計數保留。Host/IP仍遮罩，Diagnostics不含trace歷史。不做auto poll、不降頻Unavailable Slave、不新增diagnostic sensors。

## G. Search UX與Tests

TCP成功後先進搜尋範圍，首次1～247。只有按「開始搜尋」提交合法整數start≤end，才產生progress task及Modbus request。允許51～80、1～10、1～247。重新搜尋先顯示上次保存範圍，user再決定。取消不保存未完成範圍、不停止已載入Integration。

初次結果需明確勾選Slave（預設不選），再指定P404／P210及P404 Group。沒有型號猜測、automatic add或Missing automatic delete。
