# Coselig Modbus Hub v1.4.0

**Stable release.** S402 hardware acceptance has been approved for the scenarios recorded in the [acceptance report](v1.4.0-s402-acceptance.md). Other scenarios not reported there are not claimed as hardware-tested.

## 新增

- 支援 Coselig S402 四路 DI 單擊場景事件，為每顆 S402 建立 DI1–DI4 原生 Home Assistant EventEntity，事件類型為 `PRESS_END`。
- 支援 S402-only Gateway setup，不需先搜尋 Modbus Slave。
- 使用 Continuous RX Dispatcher 接收 S402 非請求事件，並與一般 Modbus 回覆分流。
- S402 EVENT 不產生額外 Modbus request；Monitor 將每個 EVENT 顯示為獨立 trace。
- Monitor 支援管理員暫停／恢復執行期背景 Poll；不修改已儲存的 `poll_interval`，reload 時清除暫停狀態。
- 多顆 S402 的 Parent Device 顯示名稱可區分，EventEntity 保持在正確的 Parent 下。

## 通訊與地址規則

- 每個 Gateway socket 只有一個 Continuous RX reader。S402 EVENT 不完成 pending Modbus response，也不延長原 request timeout。
- Control 優先順序維持高於 Poll；Polling 逐 Slave 執行，不補送排程積欠的 Poll。暫停背景 Poll 不影響 Control、Scanner、Continuous RX、S402 EVENT 或 reconnect。
- S402 ID 使用獨立 namespace。啟用 S402 時普通 Modbus Slave #1 保留；既有普通 Slave #1 設定不會被自動移除。
- Config Entry schema 維持 **2.1**，無需 migration。

## 相容性

P404、P210 與 R410 原有設備能力及通訊行為維持不變。P404／P210 Dimmer 和 R410 Relay 的原有設定無需重建。
