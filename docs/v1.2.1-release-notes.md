# Coselig Modbus Hub v1.2.1

## Child Device 預設名稱

Child Device 現在使用包含型號、Slave 與輸出的完整預設名稱：

- `P404 #51 · CH1` ～ `P404 #51 · CH4`
- `P404 #51 · 雙色溫 A`／`P404 #51 · 雙色溫 B`
- `P210 #62 · CH1`、`P210 #62 · CH2`、`P210 #62 · 雙色溫 A`

LightEntity 不再重複設定 `CH1`／`雙色溫 A` entity name，讓 Home Assistant 使用 Child Device 名稱呈現，避免 `P404 #51 · CH1 CH1`。

## Registry 相容性

Child Device identifier、entity unique_id、entity_id 與 parent_device_id 均保持不變。升級會保留使用者自訂 Entity 名稱、Area 與 automation reference；重新載入不會 duplicate 或重建既有 Entity。

本版只修改 LightEntity／Child Device presentation 與測試；Protocol、Transport、Coordinator、Polling、Scanner、Monitor 與 TraceBuffer 均未修改。
