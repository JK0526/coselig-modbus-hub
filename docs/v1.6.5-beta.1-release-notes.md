# Coselig Modbus Hub v1.6.5-beta.1

這是供 HACS 使用者選擇安裝的測試版。Config Entry schema 維持 2.1，更新時可保留既有整合。

- Scanner 根據 FC03 可讀範圍推薦 P210 或 P404，並顯示可信度。低可信度需要手動選擇。
- 可在「管理已安裝裝置」修正調光器型號，重新載入後會以新設定立即驗證。A 組保留原本的識別與輸出模式。P404 改成 P210 時會移除 B 組實體，請先確認引用這些實體的自動化。
- 單一 Slave 反覆失敗後會獨立退避。CRC 引起的 TCP 軟重置會暫停接受控制，健康實體仍維持可用。真正的 TCP 斷線仍會標示 Gateway 離線，重連後優先輪詢排在故障 Slave 後面的設備。
- 修復卸載期間命令 Future 可能懸掛、重複 Gateway 建立，以及並行 Options Flow 可能覆蓋新設定。

## 安裝與實機驗證

在 HACS 開啟此整合，更新儲存庫資訊，從「重新下載」的版本選單選擇 `v1.6.5-beta.1`，安裝後重啟 Home Assistant。請驗證 P210／P404 掃描建議、既有實體識別，以及單一 Slave 發生通訊錯誤後其他設備的輪詢與控制。

不同韌體是否有相同的 CRC 特徵，以及透明 Gateway 是否會把延遲回覆送到新 TCP，仍需實機確認。100 毫秒是建連間隔，無法保證串列緩衝已清空。
