# Coselig Modbus Hub v1.5.0-beta.2

**Beta / Options Flow validation build.** The R410 Cover hardware acceptance was reported as **PASS** by the user. Stable v1.5.0 promotion remains pending real Home Assistant confirmation of this Options Flow UX.

## Device-oriented Options Flow

- Reorganizes Options Flow navigation around the physical device: device management and communication settings now have separate entry points.
- Separates adding devices from managing installed devices, with one selector for configured P404, P210, R410, and S402 devices.
- Moves P404/P210 output mode and device removal under the selected device.
- Moves R410 output allocations and Cover add/edit/remove under the selected R410, and S402 details/removal under the selected S402.
- Keeps gateway Host/Port in Home Assistant's existing native Reconfigure flow; adds the saved scan range to Communication settings.
- Back and cancel navigation does not persist partial changes. Unknown future Options are preserved.
- Makes no protocol, entity runtime, scan execution, polling, persistence-format, or Config Entry schema changes. Config Entry remains **2.1**. R410 Cover and S402 runtime behavior is unchanged.

**Hardware acceptance for R410 Cover is complete per the user's report. Validation of the new Options Flow UX on the user's Home Assistant installation is pending.** The latest stable release remains **v1.4.0**; this beta is not v1.5.0 stable.
