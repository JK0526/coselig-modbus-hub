# Coselig Modbus Hub v1.3.3

本版修正 Monitor 桌面版 Sidebar 的捲動體驗，並調整通訊統計說明文案。Config Entry schema 維持 2.1。

## Monitor

- Packet Decoder 不再 sticky 固定於 Sidebar 頂端，改為隨 Gateway、Device Health 與 Communication Statistics 一起自然捲動。
- Decoder 內容高度限制為 `min(38vh, 360px)`，長內容可在卡片內捲動。
- 使用者點選 Trace transaction 時，若 Decoder 超出桌面 Sidebar 的可視範圍，才以 `scrollIntoView({ block: "nearest", behavior: "smooth" })` 帶入視野。Snapshot、filter、pause／resume 不會觸發自動捲動，snapshot 更新保留 Sidebar scroll position。
- Mobile 維持 Sidebar 在 Trace 上方的單欄順序；Sidebar 回到自然文件流，不觸發頁面跳動。
- 通訊統計卡片下方標示「自本次啟動起累計」；這是次要說明文字，不是 metric row。數值仍使用既有 Transport counters，沒有新增 uptime 或 elapsed-time 計算。

Protocol、Scanner、Coordinator、Transport、Polling、TraceBuffer 與 Monitor backend 均未修改；沒有新增 WebSocket snapshot 欄位或 Modbus request。Monitor 維持唯讀。

## 驗證

Frontend regression tests 覆蓋 Decoder 非 sticky、有限高度、click-only scrollIntoView、snapshot／filter／pause-resume 不主動捲動、Sidebar scroll position、Device Health／Statistics 顯示、mobile normal flow，以及 caption 語意與 metric 結構。

驗證結果：**440 Python tests passed、36 frontend tests passed、99.57% coverage**；Ruff check／format、uv lock check、JSON parse 與 `git diff --check` 通過。Config Entry schema 為 2.1。
