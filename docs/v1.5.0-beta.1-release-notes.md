## R410 Momentary Cover

- Adds a native Home Assistant `CoverEntity` attached directly to the physical R410 parent Device.
- Sends one FC06 write to register `0x019B` for each OPEN, STOP, or CLOSE command. The R410 hardware owns the configured 0.1–25.0 second Momentary duration.
- Supports two-relay mode, where STOP combines the OPEN and CLOSE relay mask, and three-relay mode, with a separately mapped STOP relay.
- Allows any free Relay mapping. Relays assigned to a Cover stop operating as normal Switches; unused R410 Relays remain normal Switches.
- Keeps Cover state and position unknown because this command-only feature has no physical position feedback.
- Queues momentary actions individually in FIFO order without coalescing. Existing stateful controls retain their latest-wins behavior.
- Keeps Config Entry schema at **2.1**; no migration is required.

## Safety and acceptance

This feature is for external curtain, rolling-door, or garage-door controller **dry-contact momentary inputs**. It does not directly reverse mains motor power and does not provide motor interlocks, obstacle protection, limit-switch logic, travel timing, or position estimation. The external controller remains responsible for motor safety and limits.

**Hardware acceptance pending.** S402 and existing P404/P210/R410 poll and control behavior are intended to remain unchanged. Verify R410 coexistence, rapid command behavior, pulse timing, reload, and mixed-device operation with the [hardware acceptance checklist](v1.5.0-r410-cover-acceptance.md). Do not treat automated tests as real-device acceptance.
