# Coselig Modbus Hub v1.6.2

Patch release adding assumed state for command-only R410 Covers.

## R410 Cover assumed state

- A successful **OPEN** command sets the assumed state to **open**.
- A successful **CLOSE** command sets the assumed state to **closed**.
- A successful **STOP** command resets the state to **unknown**.
- Restart, integration reload, and recovery after Gateway or R410 Slave communication becomes available reset the state to **unknown**.
- The state represents the last successfully issued Home Assistant command; no physical position feedback is added.
- Unavailable Gateway or R410 Slave communication continues to make the entity unavailable.
- Failed or timed-out commands do not change the assumed state and are not retried automatically.
- No position percentage, movement, travel time, or final physical position is inferred.

## Compatibility

- No Modbus protocol changes.
- No persistence or schema changes.
- Config Entry remains **VERSION 2 / MINOR_VERSION 1**.
