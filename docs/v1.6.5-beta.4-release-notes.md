# Coselig Modbus Hub v1.6.5-beta.4

公開測試版新增 Monitor「被動 RX 監聽」。管理員可在執行期啟用，即使 Poll=0，仍可觀察 Gateway 經既有 TCP 連線轉送的完整未配對回覆。S402 事件照常處理。紀錄獨立顯示，最多 200 筆，每秒最多約 20 筆，包含接收時間、Slave、功能碼、CRC 與原始 HEX。

只會觀察 Gateway 實際轉送、既有解析器支援的完整封包。功能預設關閉，啟用不會傳送額外請求，也無法觀察 Gateway 未轉送的流量。關閉 Monitor 或卸載整合會清理監聽。繁體中文完整化仍待完成。

在 HACS 啟用預發布，重新下載 v1.6.5-beta.4 並重啟 Home Assistant。最新穩定版為 v1.6.4。
