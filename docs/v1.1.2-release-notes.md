# Coselig Modbus Hub v1.1.2

## Monitor 顏色修正

本版只調整 `monitor.js` frontend presentation。固定使用跨 HA Light／Dark theme 都清楚的狀態色：

- TX 與 TX Raw HEX：`#42a5f5`
- RX、OK 與 RX Raw HEX：`#66bb6a`
- TIMEOUT：`#ffb74d`
- CRC ERROR、ERROR：`#ef5350`
- timestamp、latency：維持 `var(--secondary-text-color)`

背景、card、一般文字仍使用 HA theme variables。Monitor backend、TraceBuffer、WebSocket protocol、Modbus traffic 與暫停／清除行為均未修改。
