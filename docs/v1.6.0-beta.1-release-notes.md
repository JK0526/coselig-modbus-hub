# Coselig Modbus Hub v1.6.0-beta.1

**Beta / scheduler load-validation build. Hardware acceptance pending.** v1.5.0 remains the latest stable release.

## Scheduler capacity and behavior

- Expands the stateful scheduler from the former shared 32-control limit to **256 distinct pending stateful CommandKeys per Gateway**.
- Retains an independent **32 pending ActionSlot** capacity for R410 Cover actions.
- Keeps one shared globally ordered control schedule. Stateful controls and actions retain their relative arrival order while using independent capacity budgets.
- Preserves one Transport worker and at most one Modbus request in flight.
- Preserves latest-wins for unsent stateful commands. Replacements retain their original queue position; an already in-flight request is never retroactively replaced.
- Preserves non-coalescing FIFO action behavior. Every accepted action is sent once, including repeated identical actions.
- Keeps Control > Poll, exclusive Scanner access, S402 Continuous RX, and failure cleanup that discards unsent controls without automatic replay.

The 256 limit counts distinct pending command keys, not physical devices or circuits. A typical 100+ independent whole-house control burst fits comfortably while the physical bus remains serialized.

## Compatibility

- No Modbus protocol change.
- No entity ID, unique ID, or runtime entity behavior change.
- No Config Entry or Options schema change; Config Entry remains **VERSION 2 / MINOR_VERSION 1**.
- No migration or persisted scheduler settings.

## Hardware acceptance

Automated regression covers queue capacity, mixed ordering, polling, Scanner exclusivity, failure/no-replay, and S402 event routing. **Real Home Assistant / Gateway load acceptance remains pending.** Follow the [scheduler acceptance checklist](v1.6.0-scheduler-acceptance.md); do not treat automated tests as hardware evidence.
