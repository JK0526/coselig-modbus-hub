# Coselig Modbus Hub v1.3.2

本版改善唯讀診斷監控的長時間閱讀體驗，並統一使用 Coselig 對外品牌。Config Entry schema 維持 2.1。

## Monitor

- Auto-scroll 關閉時，以穩定封包 key 與 viewport offset 錨定目前閱讀列；若該列被本地上限移除，優先定位時間較近的後續封包，不自動跳到最新位置。
- Browser page 以記憶體暫存最多 1000 筆 Trace history，去除重複 snapshot entry。切換閘道器、清除或重新載入頁面時清空；暫停時仍接收並累積新資料。
- 封包選取使用 transaction stable key，不受歷史增加或裁切造成的索引變化影響。
- Desktop 使用固定 viewport workspace，原始封包與診斷 Sidebar 各自捲動；封包解析卡靠近 Sidebar 頂部，設備清單限制為 240px，通訊統計改成 compact rows。窄畫面採單欄。
- Monitor 標題、狀態欄與主要卡片標籤使用繁體中文；Raw HEX 與 Modbus FC 技術名稱維持原文，TX／RX／錯誤顏色不變。
- Backend TraceBuffer 仍為 200 筆。Local history 僅存在 browser memory，不使用 LocalStorage、Recorder 或資料庫；Clear 同時清 backend trace 與前端 history，但保留 Transport statistics。

## 品牌

- 型號選單、README、tracked docs 與可見 Release 描述統一為 Coselig 品牌；對外產品型號為 P404、P210、R410。

Protocol、Scanner、Coordinator、Transport、Polling、Queue、entity identity 與 Config Entry schema 均未改動。Monitor 為唯讀 observer；本版**零新增 Modbus request**，不提供 Modbus write/control。

## 驗證

發布前驗證：**440 Python tests passed、31 frontend tests passed、99.57% coverage**；Config Flow 行／分支覆蓋率 100%。Ruff check／format、uv lock check、翻譯 JSON parse、品牌掃描與 `git diff --check` 均通過。Protocol、Coordinator、Transport、Scanner 與 TraceBuffer 未修改。
