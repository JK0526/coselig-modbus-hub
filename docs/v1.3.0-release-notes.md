# Coselig Modbus Hub v1.3.0

Architecture + device support minor release，基於 v1.2.1。

- 新增 `DeviceProfile`／`PollSpec`／`OutputSpec`，將產品 register map、poll/decode、outputs、dimmer codec 與控制命令集中管理。
- Generic RTU 支援 FC01～FC06、UINT16 register、packed bits、動態 byte_count 與完整 echo/exception 驗證。
- Scanner 改為 common FC03 40001 discovery → family identification → model confirmation。P404/P210 仍需使用者確認；Unknown 不強制當 Dimmer，既有 model/groups 與 Missing 設備保留。
- R410（SUNWAVE R4J/R4P）新增四個原生 Switch 與四個 Child Devices；每輪一筆 FC01 start0 count4，控制使用 FC05，沿用 optimistic state 與既有 queue。
- R410 DI inputs currently not exposed。FC02 僅供 Scanner identification；無 DI runtime poll、binary sensors、DI config、Scene、Momentary 或硬體 Toggle command。
- P404 維持 FC03 0x082A count4；P210 single/CCT 永遠 count2。`0x05xx` dimmer codec、brightness/CCT conversion、最低亮度、queue capacity32、failure threshold3、backoff、Poll=0 與 Monitor UI 保持原行為。
- 保留 v1.2.1 entity_id、unique_id、Parent/Child IDs、自訂名稱、Area 與 automation reference。Config Entry schema 維持 2.1，更新後重啟 HA，不需刪除整合。

詳細設計與驗證範圍見 [v1.3.0 architecture](https://github.com/JK0526/coselig-modbus-hub/blob/v1.3.0/docs/v1.3.0-architecture.md)。R410 行為已通過 loopback 與 HA registry 測試；原始 SUNWAVE PDF 未出現在本次工作區／附件，產品 register map 依使用者提供的明確規格，仍需現場設備驗收。

發布前驗證：433 Python tests PASS、6 frontend tests PASS、整體 branch coverage 99.52%（v1.2.1 為 99.44%）。Config Flow、Profiles、Protocol、Scanner、Switch 均為 100% 行／分支涵蓋。Ruff、format、git diff --check 通過。
