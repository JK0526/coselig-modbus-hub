# Coselig Modbus Hub v1.3.1

本版重整 Home Assistant 原生 Config Flow 的設備管理意圖，並將唯讀 Modbus Monitor 擴充為診斷儀表板。Config Entry schema 維持 2.1；P404／P210／R410 protocol、polling、Transport queue 與實體識別策略不變。

## Config Flow

- Options 首頁分為「設備管理」與「通訊設定」；設備管理提供新增／搜尋、修改、移除三個獨立流程。
- 新增頁只列本次找到的 New Slave。Existing／Missing 只做狀態說明，不進入 Model／輸出模式頁，也不能由新增流程刪除。
- 沒有新設備時明確顯示結果，可重新搜尋、修改範圍或返回；既有及 Missing 設定維持不變。
- Dimmer 型號頁將 P404 設為預設，並顯示 P404 與 P210 的完整型號說明。R410 唯一候選時略過型號與輸出模式頁，直接到摘要。
- Output Mode 以「輸出 1＋2／輸出 3＋4」、「兩路獨立調光／一組雙色溫」呈現，底層仍儲存 `group_a`／`group_b` 的 `single`／`cct`。
- Add／Edit／Remove 都有摘要與明確確認；Remove 支援多選，只有獨立移除流程能刪設備。確認前的變更留在 Flow 記憶體。
- 修改一次一台 Slave；未改動設備及未知 future options 保留。既有 options 作為基底，只更新 `devices` 及新增確認時使用的搜尋範圍。

## Diagnostic Monitor

- 桌面版採 Raw Trace 與診斷 Sidebar 雙欄，窄畫面轉單欄；新增 Gateway metrics、runtime communication counters、Slave-level Device Health 與 Packet Decoder。
- 增加前端 Slave／類型篩選、裝置列點擊篩選、獨立 Auto-scroll。Pause 仍只凍結畫面；Clear 只清 Trace 與 Decoder selection，不清統計 counters。
- Packet Decoder 支援 FC01～FC06、FC81～FC86 exception、R410 Relay state／FC05 與 P404／P210 dimmer register 語意、FC06 transition／target。Trace status 是 CRC／交易結果權威來源。
- 所有新增資料只讀 Coordinator、Transport 統計、Device metadata 與現有 TraceBuffer。仍使用約500ms changed-only subscription；**不新增任何 Modbus request、Recorder query、儲存或寫入功能**。狀態色沿用 v1.1.2 固定配色。
