# Coselig Modbus Hub v1.6.0

Stable release.

## Scalable control scheduler

- Each Gateway supports up to **256 distinct pending stateful CommandKeys**.
- Unsent same-key commands use latest-wins; replacement keeps the original queue position.
- R410 Cover actions retain an independent budget of **32 pending ActionSlots** and remain FIFO without coalescing.
- Stateful commands and actions share one globally ordered control schedule and independent capacity budgets.
- A single Transport worker continues to serialize Modbus traffic, with one request in flight at a time.
- Control remains higher priority than Poll.

## Reliability invariants

- Uncertain writes are never automatically replayed.
- Failure discards unsent stateful commands and actions.
- Scanner remains exclusive, and S402 Continuous RX remains independent.
- Polling behavior remains unchanged.
