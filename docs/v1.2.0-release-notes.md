# Coselig Modbus Hub v1.2.0

## Native Child Devices

每個 Modbus Slave 現在有一個穩定的 Parent Device：

- Parent identifier 維持 `(coselig_modbus_hub, {entry_id}_slave_{slave})`。
- P404 的 CH1～CH4／Group A／Group B，以及 P210 的 CH1／CH2／Group A，各自是 Parent 底下的原生 HA Child Device。
- Child 只保存自己的 identifier、名稱與真實 `parent_device_id`；不使用 `via_device_id`，也不複製 manufacturer、model、firmware 或 connection metadata。
- Entity unique_id、entity_id、使用者自訂名稱與 Entity Registry Area 維持既有規則。

這讓多通道輸出可以在 HA 原生 Entity Registry 中各自指定 Area。Child 未指定自己的 Area 時，繼承顯示由 HA registry 處理，整合不保存 Area mapping。

## v1.1.2 相容

升級時保留既有 Parent Device 與所有 entity unique_id。舊版所有 LightEntity 暫時掛在 Parent 的 registry 項目，重新載入後會由 HA 將相同 unique_id 的 entity 連到對應 Child，不刪除或重建 entity_id，也不覆寫名稱或 Area。輸出模式變更仍沿用既有 P404／P210 registry lifecycle。

## Protocol scope

本版只調整 Device Registry 與 LightEntity 的裝置關係；Modbus protocol、Transport、Coordinator、polling、Scanner、Monitor backend、TraceBuffer 與 WebSocket protocol 均未修改。

## 驗證

新增與更新測試涵蓋 Parent／Child 建立、P404/P210 CCT child identifiers、v1.1.2 registry migration、名稱與 Area 保存，以及 reload／rescan lifecycle。發布前執行完整 Python suite、Ruff、format check、coverage 與 frontend Node tests。
