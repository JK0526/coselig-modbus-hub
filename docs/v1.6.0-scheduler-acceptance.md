# v1.6.0 Scheduler Acceptance

## Status

Scheduler software / automated acceptance: **PASS**.

Large-scale 100+ physical circuit deployment stress test: **NOT DIRECTLY TESTED**.

The capacity, ordering, latest-wins, Action FIFO, failure cleanup, Poll interaction, Scanner exclusivity, and S402 routing checks below were validated by automated Transport stress and regression tests. These are simulated requests against a loopback Gateway; they are not evidence of a 100+ physical-device installation or a large-site deployment.

## Automated validation

- [x] 256 distinct pending Stateful CommandKeys accepted; the 257th new distinct key is rejected.
- [x] Same-key replacement is accepted at full stateful capacity and keeps the original queue position.
- [x] Only the latest unsent same-key value is transmitted; repeated updates use one pending slot.
- [x] 100-key whole-house burst simulation sends each expected key once.
- [x] User override during a pending burst replaces the unsent value without transmitting the stale value.
- [x] In-flight boundary: the current request completes, then the newer same-key request is sent separately.
- [x] 32 ActionSlots are accepted; the 33rd pending action is rejected.
- [x] Stateful and Action capacity budgets are independent, including the 256 + 32 combined pending case.
- [x] Stateful controls and Cover actions retain one shared global ordering; replacements keep their original position.
- [x] Repeated identical Cover actions do not coalesce and actions remain FIFO.
- [x] Control > Poll and polling resumes after controls drain.
- [x] Scanner exclusive access waits for both pending control classes to drain.
- [x] Timeout, disconnect, and CRC/protocol failure discard unsent stateful controls and actions.
- [x] Discarded writes are not replayed after reconnect.
- [x] S402 events remain ordered and do not consume control capacity or request counters during queued control load.

Automated baseline: **603 Python tests**, **39 frontend tests**, **99.96% overall branch coverage**, and **100% Config Flow line / branch coverage**.

## Physical deployment scope

Large-scale 100+ circuit physical deployment has not been directly hardware stress-tested. Automated loopback Gateway tests do not establish bus throughput, deployment capacity, or performance on a real site. This limitation does not invalidate the scheduler software acceptance or block the v1.6.0 stable release.
